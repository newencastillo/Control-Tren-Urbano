# Control óptimo en operación de trenes

El siguiente proyecto busca implementar un modelo numérico para calcular un control del freno y aceleración de un tren que minimice la energía, con distintas condiciones físicas asociadas al funcionamiento del tren, la implementación se realiza en Julia, con el paquete OptimalControl.
El modelo e implementación se basan en el trabajo de Eugene Khmelnitsky "On an Optimal Control of Train Operation".
